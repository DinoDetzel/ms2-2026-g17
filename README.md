# Sistema de Control Operativo para un Cuartel de Bomberos 

*Materia: Metodología de Sistemas II (MSII) - 2026  
*Grupo: 17  

##  Descripción del Proyecto
Este proyecto consiste en un sistema de gestión diseñado específicamente para optimizar la logística y la operatividad de un cuartel de bomberos. La plataforma permite digitalizar y centralizar el control diario de los sectores automotores, el inventario de materiales de cada autobomba y electricidad de las autobombas e instalaciones del cuartel. El objetivo principal es garantizar que todas las unidades y herramientas críticas estén siempre en condiciones óptimas para el servicio, facilitando el seguimiento del mantenimiento y haciendo mas sencillas las revisiones por el personal.

## Funcionalidades Principales
* Control de Unidades (Automotores): Seguimiento detallado del estado operativo de cada vehículo, registro de kilometraje y control de vencimientos importantes para la flota.
* Gestión de Inventario y Materiales: Administración del stock de herramientas y equipamiento especializado, abarcando áreas como trauma, rescate en altura, riesgo eléctrico y equipos de respiración autónoma (E.R.A.).
* Gestión de tareas de electricidad: Administracion de tareas de las luces de autobombas e instalaciones.
* Módulo de Revisiones Periódicas: Checklists para que el personal realice los controles de rutina. Permite asentar de forma rápida el estado operativo de cada ítem y registrar observaciones detalladas en caso de detectar fallas.
* Sistema de Alertas y Tareas: Monitoreo de novedades que permite visualizar tareas pendientes de mantenimiento general y alertar sobre equipos que necesitan revisión.
